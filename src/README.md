# Código fuente

Este directorio está reservado para el código completo usado para generar o
analizar la evidencia experimental. El adjunto `codepysensibilidad.py` no está
disponible en el checkout actual, así que no se ha creado una copia ni un
reemplazo que pudiera confundirse con el código original.

Cuando se incorpore, debe mantenerse libre de secretos y modelos binarios, y
documentar sus dependencias y parámetros de ejecución.
