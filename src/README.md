# Código fuente

Contiene el código recibido para el motor de contexto y el estudio de
sensibilidad H3:

- `codepysensibilidad.py`: motor, codificación semántica y telemetría.
- `sensibilidad_h3_paralelo.py`: ejecución de la malla factorial 5x5.

El modelo `intent_v8.pkl` no se incluye. El motor puede entrenar su clasificador
localmente cuando están disponibles sus dependencias, sin subir el artefacto
binario al repositorio.
